# Multi-Tool AI Agent

A small AI agent that routes natural-language requests to three ML/DL demo
tools: **token optimization**, **image generation**, and **video generation**.

## Structure
```
ai_agent_project/
├── agent.py                    # main entry point (intent router)
├── modules/
│   ├── token_optimizer.py      # tiktoken-style token counting + optimization
│   ├── image_generator.py      # autoencoder image generator (sklearn MLP)
│   └── video_generator.py      # latent-space interpolation -> video (OpenCV)
├── outputs/                    # generated images / video / reports
└── requirements.txt
```

## Run it
```bash
pip install -r requirements.txt
python agent.py                              # interactive mode
python agent.py "generate an image"          # single-shot mode
python modules/token_optimizer.py            # run a tool directly
python modules/image_generator.py
python modules/video_generator.py
```

## What each tool demonstrates
- **token_optimizer.py** — token counting, prompt compression, sliding-window
  chat memory, and response caching.
- **image_generator.py** — a feed-forward neural network trained as an
  autoencoder on procedurally generated shape images; new images are
  generated by decoding random latent vectors.
- **video_generator.py** — reuses the trained decoder and produces a video by
  linearly interpolating between random points in latent space and decoding
  each step into a frame.
- **agent.py** — a TF-IDF + Logistic Regression intent classifier that reads
  the user's request and calls the matching tool (a simplified version of
  function-calling / tool-use in modern LLM agents).
